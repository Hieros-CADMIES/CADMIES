Interactive visualization of the CADMIES knowledge network

The mycelium map is a force-directed graph showing all concepts in the CADMIES knowledge network. Each node is a concept. Each connection is a relationship — builds_upon, related_to, or contradicts.

  • 🔄 Drag nodes to rearrange
  • 🔍 Scroll to zoom
  • 👆 Hover for concept name
  • 🖱️ Click to highlight connections
